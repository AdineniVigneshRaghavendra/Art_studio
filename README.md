
PROJECT NAME: Art Studio
![Generative Art Studio](preview.png)

THEME: Electro Art


it is a fun art project where you can play with  colorful particles and connect them ✌🏻😌.

My project is interactive and u can create cool  stuff with it and save it in ur pc...



Below points will explain how to use the prjct to create ART 😉:

Use the Particles slider to change the number of particles.

Adjust the Speed slider to control their movement.

Select a pattern from the dropdown menu.

Click Randomize to try a different arrangement.

Use Pause and Resume to control the animation.

Click Save Artwork when you want to save your creation.

Use Reset to return to the starting setup.

i made this project using html,css and javascript.
